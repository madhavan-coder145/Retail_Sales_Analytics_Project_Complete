# Retail Sales & Customer Performance Analytics

## Objective
Analyze 50,000 retail transactions to understand sales, profitability, customer behavior, product performance, and city-level trends.

## Tools
- Excel
- SQL
- Python (Pandas, NumPy, Matplotlib)
- Power BI
- Git/GitHub

## Dataset
50,000 synthetic retail transactions covering 2024–2025 with:
Order ID, Order Date, Customer ID, City, Category, Product, Quantity, Unit Price, Discount, Sales, Profit, Payment Method.

## Workflow
1. Data collection / dataset generation
2. Data cleaning in Excel and Python
3. SQL analysis
4. Exploratory Data Analysis
5. Power BI data model and dashboard
6. Business insights and recommendations

## Business Questions
- What are total sales and profit?
- Which categories and cities perform best?
- Which products drive revenue?
- How are sales changing month to month?
- Which payment methods are most used?
- Which customers generate the most revenue?
- Where are profit margins weakest?

## Power BI Dashboard
KPI cards:
- Total Sales
- Total Profit
- Orders
- Customers
- Profit Margin
- Average Order Value

Visuals:
- Monthly Sales Trend
- Sales by Category
- Sales & Profit by City
- Top 10 Products
- Payment Method Distribution
- Interactive slicers for Date, City, Category, Product

## Key Insights
Run the supplied SQL/Python analysis on the final cleaned dataset and document the strongest 4–6 findings with numbers.

## Business Recommendations
Tie each recommendation to a measured finding, for example:
- Improve margin on low-margin categories.
- Focus promotions on high-value customer segments.
- Review city-level underperformance.
- Optimize inventory around high-demand products.
